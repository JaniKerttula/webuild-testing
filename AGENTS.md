# AGENTS

## General

- Keep translations up-to-date after every operation that changes user-facing text, labels, messages, or content.

## Frontend Development

- Default to single-page application navigation within the existing shell.
- Do not add URL-backed routing, router libraries, or deep-link navigation unless the user explicitly asks for them.
- Build UI with component-based patterns.
- Prefer existing generic components for layouts and shared structure before adding page-specific markup.
- When existing components are not enough, create or extract reusable components so look-and-feel stays consistent across pages.
